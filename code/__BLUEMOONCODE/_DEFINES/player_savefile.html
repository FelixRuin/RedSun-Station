Space Station 13 - Modules - Types — Define Details

code/__BLUEMOONCODE/_DEFINES/player_savefile.dm

PLAYER_SAVEFILE_HOLD_MAXСколько savefile игроков держим открытыми одновременно. Открытый файл держит в памяти процесса примерно втрое больше своего размера (сейв на 60 слотов - около 3 МБ), поэтому держим немного.
PLAYER_SAVEFILE_HOLD_IDLEСколько держим открытым savefile, к которому никто не обращается.
PREF_JOURNAL_MAX_BYTESЖурнал одиночных ключей крупнее этого уходит в сам savefile, а не дописывается дальше.
PREF_JOURNAL_MAX_AGEЖурнал, начатый раньше этого срока, не дописывается: сброс уходит в сам savefile и сливает журнал. Столько же правка ждала диска до журнала, так что журнал держит не больше десяти минут правок.
PREF_JOURNAL_BASE_KEYКлюч блока журнала с отпечатком savefile на момент начала журнала: если файл с тех пор менялся мимо журнала, блок устарел.
PREF_JOURNAL_BLOCK_BEGINСтрока, с которой начинается каждый блок журнала: обрывок до неё (недописанный блок) не читается.
PREF_JOURNAL_BLOCK_ENDСтрока, которой заканчивается каждый дописанный блок журнала: блок без неё оборван и не читается.
PREF_JOURNAL_EPOCH_KEYКлюч поколения в блоках журнала прошлого формата: при чтении пропускается.
PREF_JOURNAL_EPOCH_SAVE_KEYКлюч savefile со счётчиком слияний журнала: его подъём наверняка меняет отпечаток файла.
PREF_JOURNAL_MERGING_SAVE_KEYКлюч savefile с отпечатком файла до начатого слияния журнала: слияние, оборванное падением, доводит следующий мир.
